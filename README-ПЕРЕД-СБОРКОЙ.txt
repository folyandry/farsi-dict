GOLVAZE: сборка Android APK через GitHub Actions

Что находится в архиве
- android/ — готовая Android-оболочка Golvaze.
- .github/workflows/build-apk.yml — автоматическая сборка APK.
- Исходные index.html, sw.js, manifest.webmanifest и иконки приложение возьмёт из корня твоего репозитория при сборке.

ВАЖНО
Этот архив не содержит и не заменяет исходный сайт. Он добавляет отдельную Android-оболочку.
Веб-версия в корне репозитория останется без изменений.
Приложение будет открывать локальную копию файлов сайта, встроенную внутрь APK. После первой сборки оно сможет запускаться без подключения к интернету; внешние веб-шрифты могут потребовать сеть при первом открытии.

КАК ДОБАВИТЬ В GITHUB С ТЕЛЕФОНА
1. Распакуй этот ZIP в телефоне.
2. Открой репозиторий https://github.com/folyandry/farsi-dict
3. Нажми Add file → Upload files.
4. Загрузи содержимое распакованного архива, сохранив структуру папок:
   - папку .github с файлом workflows/build-apk.yml
   - папку android со всеми вложенными файлами
   - этот README можно не загружать.
5. Нажми Commit changes.

СБОРКА
После загрузки GitHub Actions автоматически запустит сборку. Её также можно запустить вручную:
репозиторий → Actions → Build Golvaze APK → Run workflow.

ГДЕ ЗАБРАТЬ APK
Открой завершившийся запуск workflow, прокрути до раздела Artifacts и скачай Golvaze-APK.
Внутри будет app-debug.apk. Это устанавливаемый APK для Android.

ПОВЕДЕНИЕ КЛАВИАТУРЫ
В Android-оболочке задан режим adjustNothing: Android не должен менять высоту окна WebView при открытии клавиатуры. Страница использует уже имеющуюся в исходном index.html настройку overlays-content и фиксированный фон.
Это целевая настройка для устранения скачка фона, но окончательно подтвердить поведение можно только после установки APK на телефоне.

ХРАНЕНИЕ СЛОВ
Слова, которые будут добавлены в APK-версию, хранятся отдельно от данных Chrome/браузерной PWA. Если в браузерной версии уже есть личные слова, перед переходом их нужно экспортировать из браузера, если в интерфейсе доступен экспорт, и импортировать в APK. Сам архив не удаляет и не меняет браузерные данные.
